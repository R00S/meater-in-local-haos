## Session Log

### 2026-11-05 — 2026.11 Marketplace documentation

**Assessment (static, no Home Assistant runtime in this workspace):**

- #190450 is a catch-all report with no confirmed root cause. The reproducible 2026.11 breakages are integration-side: imports of names dropped from the entity platform packages, removal of `async_track_state_change` and `RestoreStateData.last_states`, and `DeviceInfo` becoming a dataclass.
- KCE uses none of the removed imports; its only `DeviceInfo` is built with keyword arguments and never mutated; `async_setup_entry` keeps returning a bool, which 2026.11 still supports for custom integrations; `hacs.json` exists, so the Marketplace migration carries the repository over and keeps updating it.
- The `No setup or config entry setup function defined` line quoted in the issue is the pre-existing generic error for a module that defines no setup functions at all (typically an incomplete or misplaced install), not a new 2026.11 rule.
- No open issue in this repository mentioned 2026.11 at the time of the check.

**Docs updated:**

- `README.md` — installation now leads with Settings → Marketplace (notice, catalog search, Add from link, Install, Repairs restart, Settings → Updates) and keeps the full HACS flow under a 2026.10-and-older heading.
- `docs/USER_GUIDE.md` — §2 split into Marketplace and HACS paths; the probe table and troubleshooting now say Marketplace/HACS.
- `docs/GETTING_STARTED_MEATER.md`, `docs/GETTING_STARTED_AI_RECIPE.md` — prerequisites and Step 1 cover both paths; setup-page note added.
- `docs/VIEW_ASSIST_INTEGRATION.md` — the View Assist install points at the Marketplace first, HACS second.
- One-click entry point: `marketplace_repository` badge (owner `R00S`, repository `meater-in-local-haos`, category `integration`) in README and USER_GUIDE, plus a `hacs_repository` badge on the legacy sections.
- **Correction after review:** the first version of the badge copy claimed the Marketplace would add an unknown repository as a custom repository automatically. That behaviour came from the publisher guide and was not verified against a running 2026.11 instance, so it was replaced with what is verifiable: the badge opens the Marketplace (HACS on 2026.10 and older), and a repository that is not listed must still be added with **Add from link**, then installed.
